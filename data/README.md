# 关于本目录的数据

**这里的全部内容都是为演示编造的，不是任何真实报价。**

- `routes.json`（20 条线路）、`hotels.json`（23 家酒店）里的**价格、房型、行程安排、服务描述**均为虚构，用于驱动 demo 的检索、报价与方案书生成。
- 其中出现的酒店名与品牌名**仅作示意**，与相关品牌无任何关联、合作或授权关系，也不构成对其服务内容的描述。
- `sop.md` 是为这个 demo 写的销售话术规范，不来自任何真实公司的内部资料。

如果你要把这套系统用在真实业务上，请整体替换 `data/` 下的产品库为你自己的数据。
