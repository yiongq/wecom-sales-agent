# 快速开始

单来帮助工业销售接收询价、匹配型号、查阅库存、按规则试算，并把正式报价交给顾问审批。先用一条合成询价了解协作流程，再处理自己有权使用的材料。

## 申请与登录

通过向你介绍本项目的人申请普通试用账号，账号按需发放。没有公开密码、自助注册或自动领取入口。使用发放账号时提供的后台地址登录；账号错误或失效时联系发放人，不要反复尝试其他组织的入口。

共享试用公司里，其他成员可能看到你发送的消息。试用数据包括合成种子和试用者自行发送的内容，请勿发送个人信息、正式客户资料或凭据。真实试用消息、客户资料及追踪记录保留 7 天；合成种子跳过到期清理，但手动重置会同时清理种子与试用消息。报价仍有自己的有效期。

## 走完一条询价

1. 登录成员工作台，查看合成询价，了解「AI 接待中」「等人接手」「顾问处理中」「已成交」四种状态。
2. 在已开通的微信客服渠道里发送合成需求，例如「示例轴承 A-204，20 件，请确认规格」。扫码走真实微信，只有渠道实际开通后才可使用。
3. 系统匹配产品库；型号有歧义、缺规格或数量不满足起订量时，先补充条件。图片和表格可以协助整理，识别结果需要核对。
4. 试算以已发布产品库、阶梯价和数量规则为依据。库存是产品库快照，不代表实时 ERP 库存。
5. 创建的报价默认需要人工审批。顾问核对产品、数量和金额后批准；批准后才能外发正式报价链接。驳回会作废并转人工。
6. 客户需要真人或需求超出范围时，由顾问在工作台接手，沿原渠道回复；接手期间 AI 不继续抢答。处理完成后可按工作需要交还 AI。

## 账号能做什么

共享试用账号是普通顾问，可以处理自己负责的会话与报价。不能改产品库、销售话术或进入管理员设置，不会为了试用开放更高权限。产品库修改见[产品库](./catalog.md)，审批与接手问题见[常见问题](./faq.md)。

管理员可查看组织、成员与渠道设置。本期设置只读，成员和渠道变更联系平台处理。实际部署及联合发布进度以[更新日志](./changelog.md)为准。
