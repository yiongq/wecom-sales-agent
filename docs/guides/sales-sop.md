# 销售话术

销售话术规定工业询价的接待顺序与表达方式：先问清型号、规格、数量，再匹配产品、试算、提交审批或转人工。话术不能替代价格工具，也不能授予模型决定订单和承诺的权限。

## 谁能修改

只有 owner、admin 按现有权限编辑和发布话术。共享试用顾问不能修改。若登录后没有入口，联系管理员，不需要提升试用账号权限。

## 草稿、检查、发布

1. 在销售话术页面编辑草稿，使用合成询价检查是否能问清缺失规格与数量。
2. 运行页面提供的检查，阅读错误与警告；检查通过只代表满足发布要求，不代表已经上线。
3. 使用既有发布流程和发布闸，核对当前已发布版本。草稿不会因为保存就变成线上话术。
4. 在获准渠道发送合成询价，验证试算、审批和接手路径。不要用正式客户数据做试验。

金额、订单、链接与转人工仍由确定性代码核验。话术不得许诺未配置的折扣、实时库存或无审批报价；需求超出范围时明确交给顾问确认。

## 回滚

发现问题时由管理员使用既有版本回滚流程，核对恢复后的已发布版本，再验证一条合成询价。回滚失败需联系平台处理，不通过反复编辑掩盖失败。当前会话结果与历史报价仍按其原有数据和有效期处理。

发布前先核对[产品库](./catalog.md)；权限与人工接手疑问见[常见问题](./faq.md)。
