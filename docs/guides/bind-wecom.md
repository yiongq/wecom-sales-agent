# 绑定企业微信

单来通过企业微信的微信客服渠道接收询价。渠道由平台在维护窗口配置，本期网页只显示状态，没有填写凭据、保存或重启按钮。

## 联系平台准备接入

请由有权管理企业微信的人员联系平台，按双方约定的安全渠道提供所需材料。不要把 secret、token、AES key、真实企业或客服标识贴进会话、截图或公开问题。

平台使用现有 channel-account、channel-import 等命令行流程维护渠道，持有租户独占锁，在维护窗口应用配置并重启装载。这是平台操作说明，不需要在浏览器运行命令。成员账号也由平台通过既有命令开通或调整。

## 看懂只读状态

只有 owner 或 admin 能进入「设置 → 渠道」。普通顾问不显示设置入口。

| 状态           | 含义与下一步                               |
| -------------- | ------------------------------------------ |
| 已启用         | 持久配置允许启用，不代表当前进程已连接     |
| 已装载         | 本次启动已装载账号，仍需实际收发验证       |
| 已配置凭据     | 仅说明配过材料，页面不显示凭据内容         |
| 当前部署未启用 | 部署规则禁用该渠道；正式部署不启用网页渠道 |
| 最近入站为空   | 没有可靠入站记录，不能当作已收消息         |

页面可显示回调路径；授权设置页里的完整地址以当前部署为准，不能复制其他组织或旧环境的地址。

## 回调验证后，还要实际收发

平台完成回调验证后，请用获准的微信客服入口发送一条合成询价，确认工作台能看到消息，且客户能收到回复。仅通过回调握手不等于接入完成，点击页面也不会产生入站证据。

配置改动后重新打开或聚焦页面读取状态；需要重启的变更不会因刷新自动生效。若未装载、长时间没有入站或无法回复，把发生时间和非敏感现象反馈给平台，不提交凭据。更多排查见[常见问题](./faq.md)。
