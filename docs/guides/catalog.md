# 产品库

工业产品库是型号匹配、库存说明和报价试算的依据。请先核对编码、规格与计量单位，再看数量和价格规则。

## 编码与规格

产品编码用于区分具体条目，客户提供的型号可能有空格、大小写或别名差异。系统会尝试归一和匹配；出现多个候选时应让客户确认，不能把相近型号当成相同产品。

合成示例：「示例轴承 A-204，20 件」。这里的编码与数量只说明输入方式，不代表可购买商品或正式价格。

## 库存、起订量与阶梯价

库存来自已发布产品库的配置快照，不能据此承诺实时可售量。ERP 连接器代码已具备但尚未上线，使用前由平台确认实际发布范围。

试算会使用起订量、包装倍数、计量单位和阶梯价等已配置规则。多行询价逐行核对；不满足条件时补充或调整需求，不让模型自行决定折扣、替代产品或交期承诺。

## 查看、编辑与上架

共享试用顾问只能查看，不能修改或上架产品。owner、admin 按现有产品库权限编辑草稿、检查和发布；其他角色不要通过试用账号代做配置。未发布的修改不等于当前生效内容。

管理员修改后先检查字段与规则，再按既有发布流程生效。没有可用的上架条目时，先补产品库，不应靠话术编造库存和价格。发布或检查失败时保留草稿并处理错误，不把失败当成成功。

## 产品库与正式报价

试算结果并非已经承诺的报价。[快速开始](./quick-start.md)介绍从试算到人工审批的流程；审批前链接不能发给客户，批准后才外发。超出库内规则的需求由顾问[人工接手](./faq.md#人工接手后-ai-还会回复吗)。
