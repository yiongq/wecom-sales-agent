# 常见问题

## 如何申请试用账号

向介绍本项目的人申请，账号按需发放，不公开密码，不提供自动领取。普通账号从指定后台地址登录；账号错误、停用或失效请联系发放人。

## 为什么看不到设置或编辑入口

共享试用账号是 agent，只能处理其负责的会话和报价，不能编辑产品库、销售话术或查看设置与用量。owner、admin 可查看只读组织、成员与渠道信息；本期网页不能邀请成员、更改角色、保存渠道或修改组织。

## 渠道启用了，为什么没收到消息

配置启用、启动装载与实际入站是不同事实。回调握手通过也不代表已经收发。请联系平台核对维护窗口、重启与真实微信收发；不要贴出凭据。参见[绑定企业微信](./bind-wecom.md)。

## 试算后为什么还要报价审批

工业报价默认先由顾问审批，再向客户发正式报价链接。顾问核对型号、数量、规则和金额后批准；驳回则作废并转人工。试算不能替代承诺，不会自动完成购买或收款。

## 库存和用量是实时的吗

产品库存来自已发布配置快照。ERP 连接器代码已具备，尚未上线，不能称作实时库存。用量页依赖联合发布验证，尚未上线；开放后也只有授权管理员可以查看，模型用量统计不是服务账单。实际可用范围以[更新日志](./changelog.md)和平台开通说明为准。

## 人工接手后 AI 还会回复吗

顾问接手后，AI 停止继续接待，由顾问沿原渠道回复。客户要求真人、投诉或需求超出系统范围时可转人工。顾问处理后可按工作需要交还 AI；不要把没有送达的回复当成已通知客户。

## 共享试用能放什么数据

仅使用合成材料或你有权提供的非敏感询价。其他试用成员可能看到你的消息，勿发个人信息、正式客户资料、凭据或真实客服码。真实试用消息、客户资料与追踪记录保留 7 天；合成种子不按到期任务清理，手动重置会一起清理，重置后的旧合成链接会失效。需要数据请求或重置时联系账号发放人。

## 页面加载或搜索失败怎么办

正文与目录在没有 JavaScript 时也能阅读。搜索无结果时清除关键词再试；加载失败时点击「重试搜索」。错误地址可通过「回到首页」返回；后台查询错误请就地重试，登录失效则重新登录，不把错误理解为空数据。
