# ADR-006：产品官网复用 Caddy，文档使用 VitePress

- **状态**：采纳（owner 2026-10-31 定案；15 第 1 步登记）
- **日期**：2026-10-31
- **依据**：[15 spec R1–R3](../architecture/15-product-surface/spec.md)、[共享发布契约](../architecture/15-product-surface/contracts.md)。

## 决策

官网采用独立 site 静态产物，复用现有 Caddy；文档使用独立 docs-site 与 VitePress，内容从 docs/guides 的显式白名单复制到暂存目录再构建。Node 只服务 app；三个入口不共享成员 cookie。VitePress 版本在 B 路首次引入时固定到精确版本并提交锁文件，由整合者统一依赖，不混入 console 运行依赖。

对外内容围绕工业询价。静态站不读取租户 API、会话或凭据，不发布 spec/plan/ADR/架构/运维目录；私有品牌、完整地址和审定法律正文在发布时注入，公开构建可占位、正式发布缺项失败。搜索与源码映射同样受白名单检查，不能只隐藏导航。

## 取舍

复用 Caddy 减少托管与部署配置，静态文件仍可独立构建；代价是与 app 共用服务器故障域，发布/证书/回退需统一管理。比较过独立 Pages：隔离故障域与独立发布有收益，但本期不增加第二套托管流程；将来可迁移相同静态产物。

VitePress 提供文档导航、本地搜索与构建检查，代价是固定依赖与升级维护；手写站点更少依赖，却要自行维护这些能力。本期仅登记选型，不安装依赖、不搭页面、不部署服务。

## 发布边界

Caddy 负责批准旧工业 Host 的固定上游 Host 改写，保留路径/query/body，回调 POST 不重定向；旅游旧 Host 仅批准回调放行，其余停用。实际映射与材料另记，按 15 R12 两段上线、R6 镜像约束回退；本 ADR 不是服务器操作授权。
